# Oopsie Studio

Нативное приложение для macOS: рабочие процессы ComfyUI, библиотека медиа и простой
видеоредактор с несколькими дорожками. React + Tauri 2 + Rust; SQLite и Keychain.

[Официальная инструкция проекта](docs/SETUP.md) · [English](README.md)

Сборка: `npm ci`, затем `npm run desktop:build`. Приложение находится в
`src-tauri/target/release/bundle/macos/Oopsie Studio.app`.
Установленный пакет около 10 MiB, без Node.js, node_modules и Chromium.
Для экспорта видео нужны отдельно установленные FFmpeg и ffprobe.
Сборка подписана локально, без нотариального заверения Apple.

Cloudflare R2 подключается напрямую, без AWS CLI. Есть импорт API-графов ComfyUI,
асинхронные задания и локальное сохранение результатов. Совместимость зависит от
конкретного worker; адаптер FLUX.3 пока не реализован. Реальные Runpod/R2 тесты
не выполнены. Редактор не имеет полного набора функций CapCut.
